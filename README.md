# Cajero Automático — Taller Programación Avanzada (Grupo 83)

Simulador de cajero automático en Java (Swing), desarrollado como Taller Práctico
para la asignatura Programación Avanzada, Universidad Distrital Francisco José de Caldas.

**Estudiantes:** Juan Sebastian Vasquez Ortiz (20242020285), Juan Jose Zuñiga Murcia (20251020043)
**Profesor:** José David Álvarez

## Contenido del repositorio

- `CajeroNetBeans/` — proyecto Maven/NetBeans con el código fuente Java.
- `diagramas_uml/` — los 9 diagramas UML del sistema (modelo de negocio, casos de uso,
  clases, estados, actividad, secuencia, colaboración, componentes y despliegue).
- `informe/` — informe del laboratorio en PDF, junto con su fuente LaTeX (`informe.tex`)
  y las figuras que usa (`informe/figuras/`).

## Cómo ejecutar

Abrir la carpeta `CajeroNetBeans` como proyecto Maven en NetBeans (o cualquier IDE con
soporte Maven) y ejecutar la clase `cajero.Main`.
